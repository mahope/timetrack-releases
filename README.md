# TimeTrack til Mac og Windows

Her ligger de færdige installationsfiler til TimeTracks desktop-app. TimeTrack er dansk tidsregistrering med klippekort og fakturagrundlag til selvstændige og små bureauer.

**Hent appen på [timetrack.dk/download](https://timetrack.dk/download).** Der vælger du Mac eller Windows.

## Hvad ligger her

- Installationsfiler til Mac og Windows under [Releases](https://github.com/mahope/timetrack-releases/releases)
- `latest.json`, som appen bruger til at finde opdateringer af sig selv

Kildekoden ligger ikke her.
